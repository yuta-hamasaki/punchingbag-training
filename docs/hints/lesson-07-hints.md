# Lesson 07 Hints

## L07-T01

### Hint 1
コードコメントの3条件を、入力・処理・出力に分けて考えてください。

### Hint 2
対象ファイルですでにimportされているAPIと、直前に定義された型を使います。

### Hint 3
早期returnで対象外を除外し、必要な値を局所変数へ保存してから、最後に型どおりの値または状態を返します。
